# My Agenda

My Agenda is a personal productivity application designed to help users organize tasks, track goals, and manage study reviews in one place.

The application was developed in Python with the assistance of **OpenAI Codex and ChatGPT**.

It includes three main sections: **Agenda**, **Goals**, and **Spaced Repetition**.

## Agenda

The **Agenda** tab provides a calendar where tasks and activities can be added and organized by date.

The calendar can be displayed in two different modes:

- **Daily view** — shows the tasks scheduled for a specific day.
- **Weekly view** — provides an overview of the tasks planned for the entire week.

This makes it easier to switch between detailed daily planning and a broader view of the upcoming week.

## Goals

The **Goals** tab allows users to create goals and assign a deadline to each one.

As the deadline approaches, the application automatically displays reminders in the calendar, helping users keep track of important objectives and upcoming deadlines.

## Spaced Repetition

The **Spaced Repetition** tab is designed to help with learning and long-term retention.

Users can add a task, topic, or subject that they want to review. The application then schedules future reviews while gradually increasing the amount of time between them.

For example:

- First review: after a short interval
- Second review: after a longer interval
- Third review: after an even longer interval
- Further reviews continue with progressively larger intervals

This follows the principle of **spaced repetition**, where material is reviewed frequently at first and then at increasingly longer intervals.

## Features

- Task management through a calendar
- Daily and weekly calendar views
- Tasks assigned to specific dates
- Goal creation with deadlines
- Automatic reminders for approaching goal deadlines
- Spaced repetition system
- Automatic scheduling of future reviews
- Centralized organization of tasks, goals, and study reviews

## Technologies

- Python
- OpenAI Codex
